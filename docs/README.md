# React 遗忘曲线 Checklist 项目

一个基于 React + TypeScript 的智能待办清单系统，集成艾宾浩斯遗忘曲线、图片记录和数据可视化功能。

## ✨ 核心特性

### 📝 清单管理
- 每日待办清单
- 创建、编辑、删除任务
- 优先级设置（低、中、高）
- 分类标签管理
- 任务完成状态追踪

### 🧠 遗忘曲线集成
- **艾宾浩斯复习计划**
  - 第1次：1天后
  - 第2次：3天后
  - 第3次：7天后
  - 第4次：15天后
  - 第5次：30天后
- 创建任务时可选择加入遗忘曲线
- 到期任务自动弹出提醒
- 用户可选择加入今日清单或跳过

### 📸 图片记录
- 完成任务时上传/拍照
- 自动图片压缩
- 多张图片支持
- 图片缩略图预览

### 📊 数据可视化
- 完成趋势折线图（日/周/月）
- 遗忘曲线复习进度
- 完成率统计
- 任务分类分析

### 🎨 动效设计（洛克王国风格）
- 任务添加：滑入 + 淡入 + 旋转
- 任务完成：缩放 + 旋转 + 淡出
- 任务删除：侧滑 + 3D旋转
- 日期切换过渡动画
- 图表数据更新动画

### 📱 响应式设计
- 完全响应式布局
- 竖屏/横屏自适应
- 移动端优先设计
- 屏幕适配系统（vh/vw）

## 🛠️ 技术栈

### 核心框架
- **React 18.3** - UI 框架
- **TypeScript 5.5** - 类型安全
- **Vite 5.4** - 构建工具

### 状态管理
- **Zustand 4.5** - 轻量级状态管理
- **Immer 10.1** - 不可变状态更新

### UI 组件库
- **Material-UI 6.4** - 组件库
- **Emotion 11.13** - CSS-in-JS

### 数据存储
- **IndexedDB** - 离线数据库
- **LocalStorage** - 本地存储

### 图片处理
- **Compressorjs 1.2** - 图片压缩
- **Html2Canvas 1.4** - 截图转换

### 数据可视化
- **Recharts 2.14** - React 图表库
- **ECharts 5.6** - 高级图表库
- **Chart.js 4.4** - 轻量图表库

### 动画库
- **Framer Motion 11.8** - React 动画
- **React Spring 9.7** - 物理动画
- **Animate.css 4.1** - CSS 动画

### 日期处理
- **Day.js 1.11** - 轻量日期库
- **Date-fns 3.6** - 函数式日期工具

### 表单和验证
- **React Hook Form 7.53** - 表单管理
- **Zod 3.24** - 类型安全验证

### 工具库
- **UUID 10.0** - ID 生成
- **Lodash-es 4.17** - 工具函数
- **CLSX 2.1** - 类名管理

## 📦 快速开始

### 前置要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```
