# .instructions 项目指南

## 项目概览

**智能待办清单系统** - 基于 React + TypeScript + Vite 的遗忘曲线任务管理应用

### 🎯 核心价值
- 集成艾宾浩斯遗忘曲线，科学规划复习时间
- 图片记录完成过程
- 动效精美（参考洛克王国风格）
- 移动端友好的响应式设计

## 快速导航

### 📁 关键目录
```
src/
├── components/      # UI 组件（DateSelector 已完成）
├── hooks/           # 自定义 Hooks（useChecklistData, useForgetCurve）
├── store/           # Zustand 状态管理
├── services/        # IndexedDB 持久化层
├── utils/           # 工具函数（遗忘曲线、日期、图片）
├── types/           # TypeScript 类型定义
└── assets/styles/   # SCSS 样式（屏幕适配系统）
```

### 🔑 核心文件
| 文件 | 用途 |
|------|------|
| `src/utils/forgetCurveUtils.ts` | SM-2 算法：1/3/7/15/30 天复习间隔 |
| `src/utils/dateUtils.ts` | 日期工具函数（14+ 个） |
| `src/utils/imageUtils.ts` | 图片压缩、验证、缩略图 |
| `src/store/checklistStore.ts` | 清单数据状态管理 |
| `src/store/forgetCurveStore.ts` | 复习日程状态管理 |
| `src/services/storageService.ts` | IndexedDB CRUD 操作 |
| `src/hooks/useChecklistData.ts` | 清单数据 Hook |
| `src/hooks/useForgetCurve.ts` | 复习管理 Hook |
| `src/assets/styles/mixins.scss` | 屏幕适配 Mixins（cspx、cispx） |

## 架构设计

### 分层架构
```
UI Components (React)
        ↓
Custom Hooks (useChecklistData, useForgetCurve)
        ↓
State Management (Zustand stores)
        ↓
Services (storageService)
        ↓
Browser APIs (IndexedDB, Canvas)
```

### 数据流
```
用户操作 → Component → Hook → Store → Service → IndexedDB
                ↓
           Re-render
```

## 屏幕适配系统

设计基准：**1136×640px**

### Mixins 用法
```scss
// 固定尺寸（竖屏 vh，横屏 vw）

@include cspx(font-size, 16px);

// 动态缩放（比例系数 0.5-1.5）
@include cispx(padding, 0.8, 20px);  // 80% of cspx value
```

## 遗忘曲线实现

### 核心算法
```typescript
// 5 级复习计划
第1次：0 天（初始）
第2次：1 天后
第3次：3 天后
第4次：7 天后
第5次：15 天后
第6次：30 天后（长期记忆）
```

### 关键函数
```typescript
calculateNextReviewDate(level, date)  // 计算下次复习日期
calculateEaseFactor(quality)          // SM-2 难度因子
shouldRemindReview(schedule)          // 是否需要提醒
getDaysUntilNextReview(schedule)      // 距离复习天数
```

## 常见问题解决

### 导入问题
使用路径别名而非相对路径：
```typescript
// ✅ 正确
import { useChecklistData } from '@/hooks/useChecklistData'

// ❌ 避免
import { useChecklistData } from '../../../hooks/useChecklistData'
```

### 样式适配
所有固定尺寸必须使用 Mixins：
```scss
// ✅ 正确
@include cspx(padding, 20px);

// ❌ 避免
padding: 20px;  // 在不同屏幕尺寸不一致
```

### 类型检查
添加新类型到 `src/types/index.ts`，保证项目类型完整性。
