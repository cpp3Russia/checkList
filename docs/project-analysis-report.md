# CheckList 项目分析报告

## 项目概述

**CheckList** 是一款基于 React + TypeScript 构建的智能任务管理桌面应用，核心亮点是融合了**艾宾浩斯遗忘曲线复习系统**。除任务管理外，还集成了专注番茄钟、实时航班模拟、白噪音生成器等创意功能。

| 维度 | 内容 |
|------|------|
| 技术栈 | React 18 + TypeScript + Vite |
| 状态管理 | Zustand（immer + persist） |
| UI 框架 | MUI (Material UI) v5 |
| 本地存储 | IndexedDB + localStorage |
| 图表 | Recharts |
| 部署 | GitHub Pages |

## 一、Bug 清单

### CRITICAL 严重 Bug（3个）

#### Bug #1 — 导航按钮使用 onMouseEnter 而非 onClick
- **文件**: `src/App.tsx:833`
- **问题**: 顶部导航按钮绑定 `onMouseEnter` 事件切换视图，鼠标悬停即切换页面，误触率极高
- **修复**: 将 `onMouseEnter` 改为 `onClick`

#### Bug #2 — 计时器刷新后时间跳变
- **文件**: `src/store/timerStore.ts:90-98`
- **问题**: `getElapsedMs()` 用 `Date.now() - startTime` 计算，页面刷新后会把刷新期间所有"墙钟时间"计入计时，专注时长被严重高估
- **修复**: persist 持久化时，若 `isRunning=true`，将当前累积时间保存并将 `isRunning` 改为 false

#### Bug #3 — forgetCurveStore 使用 Map + immer 不兼容
- **文件**: `src/store/forgetCurveStore.ts:17`
- **问题**: Immer 默认不自动处理 `Map` 类型，`Map.set()` 后 React 组件不会重新渲染，复习提醒列表无法更新
- **修复**: 将 `Map<string, ForgetCurveSchedule>` 替换为 `Record<string, ForgetCurveSchedule>`

---

### HIGH 高优先级 Bug（4个）

#### Bug #4 — 导航缺少 Settings 入口
- **文件**: `src/App.tsx:108-111`
- **问题**: `navItems` 只有 tasks 和 statistics，用户无法导航到设置页

#### Bug #5 — 设置页数据管理按钮无实际操作
- **文件**: `src/pages/SettingsPage.tsx:147-155`
- **问题**: 导出数据、导入数据、清空所有数据三个按钮均无 `onClick` 处理函数

#### Bug #6 — Statistics ObjectStore 重复索引
- **文件**: `src/services/storageService.ts:59-64`
- **问题**: `keyPath: 'date'` 与 `createIndex('date', 'date', { unique: true })` 冲突，Firefox 中可能抛出 `ConstraintError`

#### Bug #7 — 完成操作传入旧计时器时长
- **文件**: `src/components/ChecklistItem/ChecklistItem.tsx:~89`
- **问题**: Checkbox 完成任务时传入 `item.completedDurationMs` 旧值，应从 timerStore 获取实时计时
