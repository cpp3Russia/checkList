## 🎨 详细动效说明

### 1️⃣ 中心缩放淡入（最常用）
**适用场景**：提示、奖励、确认
```
进场动画：
  - 初始状态：scale(0.7), opacity(0)
  - 75% 关键帧：scale(1.05) 【弹性回弹】
  - 最终状态：scale(1), opacity(1)
  
时长：300-400ms
缓动：OutBack / OutElastic

关闭：反向 scale(1→0.8), opacity(1→0)
时长：200ms
```

### 2️⃣ 底部上滑（带弹跳）
**适用场景**：背包、菜单、商城
```
进场动画：
  - 初始状态：translateY(120%), opacity(0)
  - 中间帧：translateY(-5%) 【弹跳回弹】
  - 最终状态：translateY(0), opacity(1)

时长：350ms
缓动：OutBounce

关闭：向下 translateY(100%), opacity(0)
时长：250ms
```

### 3️⃣ 星光爆炸粒子（VFX）
**适用场景**：获得精灵、抽卡、强化成功
```
粒子配置：
  - 发射位置：弹窗中心
  - 粒子数：30-50 个
  - 生命周期：600-1000ms
  - 扩散方向：向四周放射
  - 淡出：最后 20% 时间透明度快速降为 0
  
配合缩放淡入，总时长：450-500ms
```

### 4️⃣ 翻页展开（书页/卷轴）
**适用场景**：任务书、魔法书、图鉴
```
进场动画（两阶段）：
  1. 上半页展开
     - 初始：rotateX(90°), opacity(0)
     - 最终：rotateX(0°), opacity(1)
     - 时长：300ms
  
  2. 下半页展开
     - 延迟：150ms
     - 同上阶段动画
     - 时长：300ms

总时长：600ms
缓动：InOutQuad
```

### 5️⃣ 脉冲光晕（Glow Pulse）
**适用场景**：VIP 奖励、稀有获得
```
进场 + 循环脉冲：
  - 进场：中心缩放淡入（300ms）
  - 脉冲效果：box-shadow 亮度循环
    - 0% → 50%：glow 强度 0 → 1
    - 50% → 100%：glow 强度 1 → 0
  - 脉冲时长：1000ms
  - 循环次数：3-4 次
  
脉冲颜色：金色、紫色、蓝色（按稀有度）
```

### 6️⃣ 打字机文字逐字出现
**适用场景**：NPC 对话、剧情文本
```
文字动画：
  - 每个字符延迟出现
  - 延迟间隔：50-100ms
  - 单字动画：opacity(0→1) + 微小上浮
  - 单字时长：100-150ms
  
总效果：逐字蹦出，配打字音（可选）
```

### 7️⃣ 从图标放大（Zoom From Icon）
**适用场景**：点击物品→详情弹窗、点击成就→展示弹窗
```
进场动画（两阶段）：
  1. 缩小阶段
     - 从图标位置：translate(x, y), scale(0.2)
     - 移动到中心：translate(0, 0)
     - 时长：150ms
  
  2. 展开阶段
     - 从 scale(0.2)
     - 到 scale(1)
     - 时长：250ms
  
总时长：400ms
缓动：OutBack
```

## 🎯 推荐时长和缓动速查

### 缓动函数推荐
```
快速进场（提示、确认）→ OutQuart / OutCubic
弹性进场（奖励、菜单）→ OutBack / OutElastic / OutBounce
平滑进场（对话框、过渡）→ InOutQuad / InOutCubic
加载旋转 → Linear（匀速）
```

### 推荐时长
- **很快**（200ms）：确认框、关闭动作
- **正常**（300-350ms）：基础弹窗进场
- **较慢**（400-500ms）：奖励、复杂动效
- **很慢**（600-1000ms）：翻页、打字机文字

## 💡 实现建议

### React + Framer Motion
```typescript
// 推荐用 Framer Motion，配合预设
import { motion, AnimatePresence } from 'framer-motion'

const popupVariants = {
  hidden: { scale: 0.7, opacity: 0 },
  visible: { 
    scale: 1, 
    opacity: 1,
    transition: {
      type: 'spring',
      stiffness: 200,    // 弹性强度
      damping: 15,       // 阻尼（回弹）
      duration: 0.35
    }
  },
  exit: { scale: 0.8, opacity: 0, transition: { duration: 0.2 } }
}
```

### CSS 关键帧
```scss
// 保持简洁，复杂特效用 Canvas 或粒子库
@keyframes popupIn {
  0% { opacity: 0; transform: scale(0.7) translate(0, 10px); }
  70% { transform: scale(1.08) translate(0, 0); }
  100% { opacity: 1; transform: scale(1) translate(0, 0); }
}
```
